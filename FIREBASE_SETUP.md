# Firebase Authentication Setup

The app includes full email/password and Google Sign-In auth via Firebase. To make it work in production, you need to replace the placeholder `google-services.json` with your real Firebase project config.

## Step 1: Create a Firebase project

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Click "Add project" and name it (e.g., "SanitovaCheck")
3. Enable Google Analytics if desired, then create the project

## Step 2: Register your Android app

1. In Firebase Console, click the Android icon to add an app
2. **Package name**: `com.sanitova.sanitovacheck`
3. **App nickname**: SanitovaCheck
4. **Debug signing certificate SHA-1** (get it from Android Studio):
   ```
   ./gradlew signingReport
   ```
   Look for the SHA-1 under `debug` → `AndroidDebugKey`
5. Click "Register app"

## Step 3: Download config file

1. Download `google-services.json`
2. Replace the placeholder at:
   ```
   app/google-services.json
   ```

## Step 4: Enable Authentication methods

1. In Firebase Console → Authentication → Get started
2. Enable **Email/Password**
3. Enable **Google** (and add your support email)

## Step 5: Rebuild

```bash
./gradlew :app:assembleDebug
```

## Notes

- The placeholder `google-services.json` allows the app to **compile** but auth will fail at runtime until you replace it.
- The `default_web_client_id` string (used for Google Sign-In) is auto-generated by the google-services Gradle plugin from your real config.
- If Google Sign-In doesn't work after setup, double-check that your SHA-1 fingerprint is added to Firebase project settings.
